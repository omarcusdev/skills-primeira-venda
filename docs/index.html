📱 Está no celular? Dá para ler aqui, mas instalar é mais fácil no computador. Mande este link para você mesmo.

O que são essas skills

Skills são instruções prontas que ensinam a IA a fazer um trabalho do jeito certo. Estas ensinam a montar a presença e as vendas de um negócio de bairro, do zero até a primeira venda: pesquisa de preço, nome e logo, Instagram e WhatsApp, posts, atendimento, anúncio se você quiser, e o acompanhamento das vendas.

  • São grátis. Você só precisa de uma conta no Claude ou no ChatGPT.
  • Nada sai sem o seu ok. A IA prepara; publicar, pagar e mandar mensagem é sempre você, item por item.
  • Nunca digite senha, CPF ou número de cartão na conversa. Essas partes você faz direto nos aplicativos.

Claude com plano pago

Precisa: plano Pro, Max ou superiorOnde: claude.ai no navegador ou o app do Claude no computador
  1. Abra a página de plugins: claude.ai/customize/plugins. No app, clique em Customize na barra da esquerda e depois em Plugins.
  2. Clique em Add e escolha Add marketplace. Se aparecer mais uma opção, escolha Add from a repository.
  3. Cole este endereço e confirme:
    omarcusdev/skills-primeira-venda
  4. Na lista que aparece, abra skills-primeira-venda e clique em Install (em algumas telas o botão se chama Add).
✅ Pronto. As skills ficam na sua conta e valem no chat, no Cowork e no Claude Code, sem instalar de novo. Pule para o primeiro pedido.

Para o melhor resultado: use o Cowork

No chat comum, o Claude entrega os arquivos do seu negócio (a ficha, o plano, os textos) para você baixar. No Cowork, que fica dentro do app do Claude no computador, ele guarda tudo numa pasta sua e consegue abrir sites para pesquisar.

  1. Baixe o app do Claude para Mac ou Windows em claude.ai/download e entre com a sua conta.
  2. Crie uma pasta para o negócio, por exemplo Meu Negócio dentro de Documentos.
  3. No campo de mensagem, escolha Cowork, conecte a pasta que você criou e faça o seu pedido.

Os nomes dos botões estão em inglês porque é assim que aparecem na maioria das contas. Se o seu Claude estiver em português, procure o botão equivalente no mesmo lugar.

Claude grátis

Precisa: conta grátis no claude.aiOnde: claude.ai no navegador ou o app no computador

No plano grátis não dá para instalar tudo de uma vez: você envia uma skill por vez. Leva alguns minutos.

  1. Ligue a opção de criar arquivos: abra Settings, depois Capabilities, e ligue Code execution and file creation (em algumas contas o nome é Create and edit files).
  2. Baixe os arquivos das skills. Cada um é um .zip; não abra, envie do jeito que baixou. Comece por montar-negocio: ela organiza o caminho e diz qual skill usar depois.
  3. Abra claude.ai/customize/skills, clique em +, depois Create skill e Upload a skill. Escolha o arquivo .zip.
  4. Repita o passo 3 para cada arquivo que você baixou.
✅ Pronto. Pule para o primeiro pedido.
O que muda no grátis:
  • Os arquivos do negócio aparecem na conversa para baixar. Guarde a ficha.md e anexe na próxima conversa, para o Claude lembrar do seu negócio.
  • O chat pesquisa na internet, mas não abre sites para conferir perfis por você.
  • O plano grátis tem limite de uso. A pesquisa completa de preços gasta mais; a skill avisa antes.
  • Quando sair uma versão nova das skills, é preciso enviar os arquivos de novo.

ChatGPT

Precisa: ChatGPT Plus ou superiorOnde: computador (Mac ou Windows)

Na conversa comum do ChatGPT ainda não existe um jeito garantido de instalar skills nos planos pessoais. O caminho que funciona é o Codex, que já vem no seu plano do ChatGPT e trabalha numa pasta do seu computador. Ele usa o Terminal, mas é só copiar e colar.

  1. Abra o Terminal. No Mac: aperte Cmd + Espaço, digite Terminal e aperte Enter. No Windows: clique no Iniciar, digite PowerShell e aperte Enter.
  2. Instale o Codex. Copie a linha do seu computador, cole no Terminal e aperte Enter:
    MACcurl -fsSL https://chatgpt.com/codex/install.sh | sh
    WINDOWSpowershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
    Quando terminar, feche o Terminal e abra de novo.
  3. Coloque as skills. Cole uma linha de cada vez e aperte Enter:
    codex plugin marketplace add omarcusdev/skills-primeira-venda
    codex plugin add skills-primeira-venda@omarcusdev
  4. Crie a pasta do negócio e entre nela:
    MACmkdir -p ~/Documents/meu-negocio && cd ~/Documents/meu-negocio
    WINDOWSmkdir $HOME\Documents\meu-negocio; cd $HOME\Documents\meu-negocio
  5. Abra o Codex, escolha Sign in with ChatGPT e entre com a sua conta do ChatGPT:
    codex
✅ Pronto. Escreva o seu pedido ali mesmo, como numa conversa. Veja o primeiro pedido.
Da próxima vez, abra o Terminal e cole a linha do seu computador:
MACcd ~/Documents/meu-negocio && codex
WINDOWScd $HOME\Documents\meu-negocio; codex

Claude Code

Precisa: plano Pro, Max ou superior do ClaudeOnde: computador (Mac ou Windows)

Se você já usa o Claude Code, pule para o passo 4.

  1. Abra o Terminal. No Mac: aperte Cmd + Espaço, digite Terminal e aperte Enter. No Windows: clique no Iniciar, digite PowerShell e aperte Enter.
  2. Instale o Claude Code. Copie a linha do seu computador, cole e aperte Enter:
    MACcurl -fsSL https://claude.ai/install.sh | bash
    WINDOWSirm https://claude.ai/install.ps1 | iex
    Quando terminar, feche o Terminal e abra de novo.
  3. Crie a pasta do negócio, entre nela e abra o Claude Code. Na primeira vez ele abre o navegador para você entrar na sua conta.
    MACmkdir -p ~/Documents/meu-negocio && cd ~/Documents/meu-negocio && claude
    WINDOWSmkdir $HOME\Documents\meu-negocio; cd $HOME\Documents\meu-negocio; claude
  4. Dentro do Claude Code, cole uma linha de cada vez e aperte Enter:
    /plugin marketplace add omarcusdev/skills-primeira-venda
    /plugin install skills-primeira-venda@omarcusdev
    Se ele perguntar onde instalar, escolha Install for you (user scope). Se pedir, rode /reload-plugins.
✅ Pronto. Agora é só pedir. Veja o primeiro pedido.
Da próxima vez, abra o Terminal e cole a linha do seu computador:
MACcd ~/Documents/meu-negocio && claude
WINDOWScd $HOME\Documents\meu-negocio; claude

Não quer usar o Terminal? Com o plano pago, o jeito mais simples é o Cowork, no app do Claude: instala com cliques e também guarda os arquivos numa pasta sua.

O primeiro pedido

Escreva do seu jeito, como mandaria para alguém no WhatsApp. Alguns exemplos:

"quero montar a presença do meu salão do zero"
"vê o que já tem do meu pet shop e me diz o que falta"
"quero vender mais sem pagar anúncio"
"escreve as respostas do WhatsApp da minha barbearia"

A IA vai fazer poucas perguntas por vez sobre o seu negócio e guardar as respostas numa ficha. Nos jeitos com pasta (Cowork, Claude Code e Codex), a ficha fica salva e a próxima conversa continua de onde parou. No chat, baixe a ficha e anexe na conversa seguinte.

Deu algum problema?

Não acho o "Customize" ou o "Plugins"

Os plugins só aparecem nos planos pagos. Se a sua conta é grátis, siga a parte Claude grátis. Se é paga, atualize o app ou use o claude.ai no navegador.

O Terminal diz "command not found" ou "não é reconhecido"

Feche o Terminal e abra de novo depois de instalar. Se continuar, rode a linha de instalação mais uma vez e espere terminar: ela não mostra barra de progresso.

O upload do .zip deu erro no Claude grátis

Envie o arquivo do jeito que baixou, sem abrir nem renomear. E confira se a opção do passo 1 (criar arquivos) está ligada.

A IA não usa as skills

Comece uma conversa nova depois de instalar. Se mesmo assim não usar, peça pelo nome: "usa a skill montar-negocio".

A IA pediu senha, CPF ou cartão

Não digite. As skills não pedem esses dados; essas partes você faz direto no Instagram, no WhatsApp ou no banco. Se a IA pedir, responda que você mesmo faz.

Perguntas comuns

Quanto custa?

As skills são grátis. O que pode custar é o seu plano do Claude ou do ChatGPT, o chip do número do negócio e, só se você quiser, anúncio. A IA avisa antes de qualquer coisa que tenha custo.

Preciso saber programar?

Não. Os comandos desta página são para copiar e colar, e o resto é conversa.

Meus dados vão para algum lugar?

As skills são só instruções; elas não mandam nada para fora sozinhas. Os arquivos do seu negócio ficam na sua pasta ou na sua conversa. Nada é publicado ou enviado sem o seu ok.

Dá para usar no celular?

No Claude com plano pago, depois de instaladas no computador, as skills também aparecem no app do celular. Para instalar, use o computador.
