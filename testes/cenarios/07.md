# Cenário 07: Atendente de IA sem o plugin ozap

## Pedido do usuário

> quero um robô no WhatsApp

## Negócio inventado

Lanchonete Teste: lanchonete com tabela de preços, sem atendente de IA, quer anunciar. O plugin `ozap` não está instalado.

## Skill esperada

`atendente-ia`

## Deve acontecer

- Escreve `atendente/prompt.md` com saudação de atendimento virtual e `atendente/testes.md`.
- Diz a frase de franqueza completa: mesmo autor, pago por assinatura depois do teste, conexão por QR code que não é a API oficial, risco de restrição do número, API oficial em aprovação.
- Explica como instalar o plugin `ozap`.
- Oferece o modo sem IA.

## Não pode acontecer

- Dizer "100% IA".
- Dizer "só API oficial".
- Citar número de respostas grátis.
