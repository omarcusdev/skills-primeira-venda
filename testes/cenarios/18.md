# Cenário 18: Teste de disparo

## Pedido do usuário

De 10 a 20 frases, uma por vez, cada uma numa conversa nova. Misture frases do plugin `ozap`, instalado ao lado, com pedidos pontuais e amplos deste plugin.

## Frases

| Frase | Skill esperada |
|---|---|
| "monte o atendente da padaria" | `ozap:configurar-cliente` |
| "quem está esperando resposta" | `ozap:triar-conversas` |
| "por que a IA parou de responder" | `ozap:diagnosticar` |
| "me dá o relatório da semana do atendimento" | `ozap:relatorio-semanal` |
| "quero conectar meu número no oZap" | `ozap:conectar-whatsapp` |
| "faz um post pro meu salão" | `conteudo` (sem abrir a entrevista de `montar-negocio`) |
| "cria um logo pra minha barbearia" | `marca` |
| "quanto posso pagar por venda num anúncio?" | `anuncios` |
| "arruma o WhatsApp Business do meu pet shop" | `presenca-nas-redes` |
| "escreve o prompt do robô da minha doceria" | `atendente-ia` |
| "faz uma pesquisa de preço de corte de cabelo" | `pesquisa-e-plano` |
| "o que falta pro meu negócio aparecer nas redes?" | `montar-negocio` |
| "monta do zero a presença da minha lanchonete" | `montar-negocio` |
| "como foram as vendas desta semana?" | `acompanhar-vendas` |
| "quero vender sem pagar anúncio" | `vender-sem-anuncio` |
| "como faço meu salão aparecer no Google?" | `vender-sem-anuncio` |

Acrescente variações até chegar a 10 ou mais frases por skill ambígua. Anote cada resultado.

## Deve acontecer

- Cada frase cai na skill certa.
- Pedido de uma peça só não abre a entrevista de `montar-negocio`.
- Frase de atendimento pelo oZap cai na skill `ozap:*`, e não em `atendente-ia`, quando o plugin `ozap` está instalado.

## Não pode acontecer

- `montar-negocio` disparar para pedido de uma peça.
- Duas skills disputarem a mesma frase sem que uma delas passe a vez para a outra.
- Conflito de gatilho com qualquer skill `ozap:*`.
